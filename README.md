# WhatsApp Clone with Jetpack Compose

This is a WhatsApp-like UI clone built using **Jetpack Compose** in Android. The app includes features like Chats, Status, Calls, and Themes. The project demonstrates the use of Jetpack Compose components, navigation, animations, and theming.

## Features

- **Chats Screen**: Displays a list of chats with user avatars, last messages, timestamps, and unread message counts.
- **Status Screen**: Shows recent and viewed status updates with user avatars and timestamps.
- **Calls Screen**: Lists favorite and recent calls with user avatars and timestamps.
- **Themes Screen**: Allows users to select from multiple themes to personalize the app's appearance.
- **Bottom Navigation Bar**: Navigates between Chats, Status, Calls, and Themes screens with smooth animations.

## Technologies Used

- **Jetpack Compose**: Modern Android UI toolkit for building native UIs.
- **Coil**: Image loading library for Compose.
- **Navigation Component**: For handling navigation between screens.
- **Material 3**: For modern and adaptive UI components.
